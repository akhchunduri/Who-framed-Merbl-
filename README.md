# Who-framed-Merbl-

In this project, the aim is to create a marble maze with repeating loops and turns. The first plan of action was to create the base and the first slide. This was detailed in the following pictures. This took around 2.5 hours as there were technical issues and the center point of the sketch was not lining up with the line protruding
<img width="900" height="1600" alt="s1" src="https://github.com/user-attachments/assets/7d2407b5-4f35-493d-a25e-cbd76b21b31c" />
Immediately after, I decided to delete the image to make slides that would go downward. For this to happen, I tried using the TRANSFORM tool, although it did not occur. Finally, I first added a line, then  created a slanted plane, then traced a zigzag pattern using the tangent tool. This created the gray slides below. Once that has been accomplished, I decided to replicate the slide by mirroring it over the RIGHT plane. This created two copies that I then transformed into place.
<img width="550" height="475" alt="slides" src="https://github.com/user-attachments/assets/f1895a2e-256f-4901-bab4-99fb7f174e76" />
After, I made a spire for the next section -- a funnel. I made a line, then created two more lines touchng at 115 degrees, after which was filleted and onset then later revolved over a previous line. I filleted the corners to make a smooth shape. The color is below and blue. Along with that, I made a marble with the same revolving mechanism.
